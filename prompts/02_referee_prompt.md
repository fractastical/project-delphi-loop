# Prompt 2 — Blinded Cross-Provider Referee Agent (`prompts/02_referee_prompt.md`)

- **Role:** Blinded Second-Company Referee Agent (e.g., `gemini-4-argon`, Google DeepMind, auditing code written by Anthropic's `claude-fable-5-1`, or vice versa)
- **Isolation Rule:** Spawned in a detached git worktree where prior audits and score tables are stripped so no model sees another model's scores.
- **Inputs Passed Into Prompt:**
  1. `rubric.yaml` (the 7 weighted dimensions on `0-100`)
  2. Target script (`example/pass1_naive_fit.py` or `example/pass2_remediated_fit.py`)
  3. Deterministic sidecar (`kg/pass1_sidecar.yaml` produced by Gate 2 `gates/2_measure_sidecar.py`, which independently computes overall RMSE, $R^2$, Head MAE, and Body MAE)
- **Output Required From Agent:**
  - `kg/pass<N>_audit.yaml` containing 0–100 scores per dimension and an explicit `remediation:` list of defects.

---

## Exact Prompt Template Sent to the Blinded Referee Agent

```markdown
You are acting as an independent, blinded referee (`blinded: true`) for the Project Delphi benchmark.

## STRICT ISOLATION PROTOCOL
You are running in an isolated worktree containing ONLY:
1. `rubric.yaml` (7 weighted dimensions on 0–100: `model-fidelity` [20], `empirical-match` [25], `parameter-expressivity` [10], `quantitative-validation` [15], `data-traceability` [10], `code-traceability` [8], `reproducibility` [12]).
2. The Builder's script: `<target_script>`.
3. The deterministic sidecar measurement file: `kg/pass<N>_sidecar.yaml` (generated by the zero-LLM verifier `gates/2_measure_sidecar.py`).

## TASK
1. Inspect every line of `<target_script>` alongside the independent metrics in `kg/pass<N>_sidecar.yaml` (`rmse_all_g`, `r2_all`, `mae_head_subset_g`, `mae_body_subset_g`).
2. Score all 7 dimensions in `kg/pass<N>_audit.yaml` on the 0–100 scale, citing exact line numbers in `<target_script>`.
3. If any dimension scores below 80, write concrete, falsifiable engineering fixes under `remediation:`. Gate 3 (`gates/3_compile_and_query_kg.py`) will compile these items into `pk:evidenceAgainst` RDF triples in `kg/pass<N>_claim.trig` to drive the next pass.
```
